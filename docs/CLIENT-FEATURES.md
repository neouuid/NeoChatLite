# 客户端产品能力与限制

## 新消息提醒（应用内）

- 会话列表页订阅 WebSocket 事件；收到 `new_message` 且满足以下条件时提醒：
  - 不是自己发的
  - 不是当前正打开的会话
  - 该会话没有开启免打扰
- 提醒形式：底部 SnackBar（发送者 + 内容摘要 + 「查看」按钮），同时在标题栏累计未读提醒角标
- 角标是「本次运行期间的提醒次数」，点击即可清零；与每个会话的服务端未读数相互独立

**限制**：没有系统级通知（原生推送/托盘），因为那需要 APNs/FCM 或各桌面平台的通知插件。
App 未运行或窗口最小化时不会提醒；后续可接 `flutter_local_notifications` 或服务端推送。

## 消息本地缓存

- 每个会话在本地保留最近 200 条消息（`shared_preferences`，键 `neochat.msgs.<convId>`）
- 打开会话时先用缓存渲染，再请求服务端覆盖，弱网/离线时不会白屏
- 收到新消息、翻页、发送后都会刷新缓存
- 缓存损坏时静默退化为「无缓存」，不影响正常流程

**限制**：明文存于本地偏好存储；敏感场景应换成加密存储。缓存不参与搜索与跨设备同步。

## 会话置顶

- 长按会话 → 置顶 / 取消置顶；置顶项显示图钉图标
- 排序由服务端完成：`pinned DESC, updated_at DESC`
- 置顶是**按用户**的（存在成员记录上），不影响其他成员
- 任何影响列表的写操作都会失效该用户的会话列表缓存

## 发送队列与重试

发消息不是「发出去就完事」——网络抖动、限流、服务端 5xx 时消息**不会丢**：

| 行为 | 说明 |
|---|---|
| 乐观展示 | 消息立刻出现在聊天页末尾，带「发送中…」 |
| 自动重试 | 网络错误 / 408 / 429 / 5xx 会退避重试（2s、5s），最多 3 次 |
| 不重试 4xx | 参数错误重试也没用，直接标记失败 |
| 手动重试 | 失败气泡点击即重试；长按可放弃 |
| 重连补发 | 实时连接恢复后自动 flush 所有失败消息 |

**已知限制**：队列只在内存里，进程被杀会丢；重启后不会补发。

## 账号安全

| 能力 | 入口 | 说明 |
|---|---|---|
| 修改密码 | 我的资料 → 账号安全 | 需当前密码；成功后清空登录态要求重新登录 |
| 找回密码 | 登录页 → 忘记密码 | 输入邮箱拿令牌 → 设置新密码；开发模式自动填入令牌 |
| 注销账号 | 我的资料 → 账号安全 | 需密码确认 + 二次弹窗，软删除 |

## 附件访问

- 上传返回 `/api/v1/files/...` 相对路径，客户端用 `session.fileUrl()` 拼上服务端地址与 token
- 图片/视频/语音/头像都走鉴权 URL；匿名访问返回 401
- 文件消息点击后用系统默认程序打开（url_launcher）

## 其它交互速查

| 场景 | 操作 |
|---|---|
| 编辑消息 | 长按自己的文本消息 → 编辑 |
| 引用回复 | 长按任意消息 → 回复 |
| 收藏 / 转发 / 撤回 | 长按消息 |
| 语音 / 视频 / 文件 | 输入栏 📎 |
| 查看他人资料 | 群聊里点发送者昵称 |
| 群资料 | 群聊右上角 → 群信息 → 编辑 |
| 免打扰 / 置顶 | 长按会话列表项 |
| 通讯录 | 会话列表 ⋯ → 通讯录 |
