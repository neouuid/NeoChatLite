# 客户端产品能力与限制

## 新消息提醒（应用内）

- 会话列表页订阅 WebSocket 事件；收到 `new_message` 且满足以下条件时提醒：
  - 不是自己发的
  - 不是当前正打开的会话
  - 该会话没有开启免打扰
- 提醒形式：底部 SnackBar（发送者 + 内容摘要 + 「查看」按钮），同时在标题栏累计未读提醒角标
- 角标是「本次运行期间的提醒次数」，点击即可清零；与每个会话的服务端未读数相互独立

**限制**：没有系统级通知（原生推送/托盘），因为那需要 APNs/FCM 或各桌面平台的通知插件。
App 未运行或窗口最小化时不会提醒；后续可接 `flutter_local_notifications` 或服务端推送。

## 消息本地缓存

- 每个会话在本地保留最近 200 条消息（`shared_preferences`，键 `neochat.msgs.<convId>`）
- 打开会话时先用缓存渲染，再请求服务端覆盖，弱网/离线时不会白屏
- 收到新消息、翻页、发送后都会刷新缓存
- 缓存损坏时静默退化为「无缓存」，不影响正常流程

**限制**：明文存于本地偏好存储；敏感场景应换成加密存储。缓存不参与搜索与跨设备同步。

## 会话置顶

- 长按会话 → 置顶 / 取消置顶；置顶项显示图钉图标
- 排序由服务端完成：`pinned DESC, updated_at DESC`
- 置顶是**按用户**的（存在成员记录上），不影响其他成员
- 任何影响列表的写操作都会失效该用户的会话列表缓存

## 其它交互速查

| 场景 | 操作 |
|---|---|
| 编辑消息 | 长按自己的文本消息 → 编辑 |
| 引用回复 | 长按任意消息 → 回复 |
| 收藏 / 转发 / 撤回 | 长按消息 |
| 语音 / 视频 / 文件 | 输入栏 📎 |
| 查看他人资料 | 群聊里点发送者昵称 |
| 群资料 | 群聊右上角 → 群信息 → 编辑 |
| 免打扰 / 置顶 | 长按会话列表项 |
| 通讯录 | 会话列表 ⋯ → 通讯录 |
